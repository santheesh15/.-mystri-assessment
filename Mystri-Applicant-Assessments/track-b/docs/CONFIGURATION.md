# Configuration — Product 1

## CLI — `experiment.py`

| Flag | Default | Description |
| --- | --- | --- |
| `--write` | `output/integrated_report.json` | Full JSON report path |
| `--trace` | `output/dicm_pipeline_trace.log` | Unified trace log |
| `--acks` | `output/customer_structured_responses.json` | Structured receipt bundle |

Example:

```bash
python experiment.py --write output/integrated_report.json --trace output/dicm_pipeline_trace.log --acks output/customer_structured_responses.json
```

---

## Scenario — `data/scenario.json`

| Field | Role |
| --- | --- |
| `snapshot_at` | Fixed “now” for rules (ISO datetime) |
| `minimum_followup_gap_hours` | Default **48** |
| `monthly_tool_budget_inr` | Cost model cap (e.g. **1500**) |
| `dry_run_only` | Assessment flag (true) |

**Important:** Use snapshot time from file — not the computer’s real-time clock — for reproducible results matching docs.
